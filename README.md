# Parchment Map (1.20.1, Forge 47 / NeoForge 1.20.1)

Клієнтський мод: карта у стилі старого пергаменту, міні-карта, мітки, маршрути, малювання.

## Збірка
Потрібна Java 17.
1. Найпростіше: завантажте офіційний Forge MDK 1.20.1-47.x (files.minecraftforge.net), скопіюйте з нього
   `gradlew`, `gradlew.bat` і теку `gradle/` у цю теку.
2. `./gradlew build`  (Windows: `gradlew.bat build`)
3. Готовий файл: `build/libs/parchmentmap-1.20.1-1.0.0.jar` → у теку `mods` (Forge 47.x або NeoForge 1.20.1).

## Керування (змінюється в Налаштування → Керування)
- M — велика карта; N — міні-карта вкл/викл; Z — масштаб міні-карти; B — мітка на місці, де ви стоїте.
- У великій карті: ПКМ/СКМ тягнути — рух; колесо — масштаб; C — до себе; Backspace — відмінити.
- Інструменти: Рух, Мітка, Шлях (точки маршруту), Малюнок, Гумка.
- Вкладки справа: Мітки (навігація, зміна, показ/ховання, видалення) та Маршрути (новий, навігація, відмінити, видалити).

Дані світу: `<тека гри>/parchmentmap/<світ>/` (data.json + PNG-регіони карти).
